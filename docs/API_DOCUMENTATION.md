# Documentación de la API REST - PlatoRestController

## Endpoints de Platos
- **GET /api/platos**: Obtiene el listado completo de platos en la carta.
- **GET /api/platos/{id}**: Obtiene el detalle de un plato específico por ID.
- **POST /api/platos**: Crea un nuevo plato (requiere rol ADMIN).
- **PUT /api/platos/{id}**: Actualiza los datos de un plato existente (ADMIN).
- **DELETE /api/platos/{id}**: Elimina un plato del sistema (ADMIN).
